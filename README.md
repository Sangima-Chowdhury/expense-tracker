# Expense Tracker

A Flask-based expense tracker web application that allows users to add, view, and delete expenses using a database.

## Features
- Add expenses
- View all expenses
- Delete expenses
- Store expense data in a database
- Dynamic rendering with HTML templates
- Basic CRUD functionality

## Technologies Used
- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- Git & GitHub

## What I Learned
This project helped me understand CRUD operations, form handling, POST requests, database storage, and dynamic page rendering using Flask and Jinja templates.
